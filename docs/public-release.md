# 本地开发与公开发布

## 保留内容

`README.md` 为公开入口；`README.local.md` 是可选个人笔记，忽略上传。
应用继续使用 `.env`，模型脚本额外支持 `.env.model.local`，前端使用 `frontend/.env.local`。
公开配置模板只使用各目录 `.env.example`，填写占位凭据和通用参数。
Shell 配置优先；应用 Settings 读取 `.env`，模型脚本的本地 profile 只作用于启动脚本。
模板变化后手动合并新字段，不覆盖已有 `.env`。不得把私有配置复制进模板。

源码、依赖清单、锁文件、测试、合成 fixtures、通用文档和部署模板可以公开。
模型权重、数据库、历史会话、依赖目录、构建产物、原始报告和个人笔记默认忽略。

## 报告

原始报告保留在原目录，本地仍可查阅。Git 只放行 `reports/README.md` 和 `reports/public/`。
新报告默认保持本地，不要通过批量重命名或取消忽略直接发布。
公开报告优先采用字段白名单：模型/依赖版本、非个人化硬件规格、参数、案例标签、
聚合指标及局限。人工检查原始问题、回答和工具结果中是否含个人数据。
去掉机器路径、内网地址、凭据和私人会话；保留真实结果和实验条件，不改写失败为成功。
第三方原始数据通过下载/导入脚本获取，保留来源和适用许可说明。

## 检查

```bash
python3 -B scripts/check_public_files.py
```

需要 Git 可执行文件。已有仓库会检查已跟踪文件和未忽略文件，因此已跟踪的私密文件仍会报错。
没有 `.git` 时只在临时目录创建 Git 元数据，用项目忽略规则计算候选文件；不初始化当前目录。
输出只有文件、行号与问题类别，不输出命中的凭据或地址。

检查范围为工作区候选文件，包括个人路径、RFC1918 地址、部分密钥格式、私密文件类型和模板凭据。
这不是 Git 历史/暂存区扫描，也不能覆盖所有秘密格式。图片和字体元数据仍需人工审核。
工作区文件通过不代表暂存区旧版本通过；提交前检查暂存内容，推送时配合密钥扫描。

## 独立公开副本

```bash
python3 -B scripts/export_public.py /tmp/ecommerce-agent-public
python3 -B /tmp/ecommerce-agent-public/scripts/check_public_files.py
```

导出前检查候选文件，失败则不创建目标。目标必须是项目外的新目录，拒绝覆盖。
只复制工作区候选文件，不复制 Git 历史、源目录的私密配置、数据或依赖；不删除源文件。
本地环境可以持续使用，公开副本用于最终审核与首次上传。
首次提交前检查公开目录，确认许可证选择及第三方数据/模型的使用要求。
本项目未替作者选择或添加开源许可证。

若在公开副本中初始化 Git，可先用 `git add --dry-run .` 查看候选，再暂存并检查
`git diff --cached --stat` 和 `git diff --cached`。差异可能包含秘密，只在自己终端查看，勿粘贴原始输出。
本流程不会代为初始化公开仓库、提交或推送。

## 已有 Git 历史

`.gitignore` 对已跟踪文件不生效。确认需要后逐个使用 `git rm --cached -- 文件名` 取消跟踪，
该操作不会删除工作区文件，但也不会清理历史。避免批量清空索引。
如真实凭据曾上传，先撤销或轮换，再按 GitHub 官方流程处理历史；导出干净副本不能撤回旧泄露。

## CI

CI 运行公开文件检查、隔离离线测试及前端构建，不应依赖个人模型路径或 GPU。
不要将 `.env` 作为 CI artifact，也不要打印环境变量、含凭据的配置展开结果或模型请求认证头。
真实模型评测和 GPU 服务启动需人工确认资源与授权，不能自动接入普通 PR 流程。
